# Pratibhimb Wedding Photography Portfolio

A static HTML, CSS, and JavaScript portfolio website for Pratibhimb.

## Deploy to Vercel

1. Import this GitHub repository into Vercel.
2. Deploy from the `main` branch. The included `vercel.json` selects the project
   root as the static output directory; no build command is required.

Portfolio videos are compressed, browser-compatible MP4 files stored as regular
repository assets under `assets/together/compressed/`. Git LFS is not required
for these videos.

All portfolio photos and videos are public when this site and repository are
public. Replace the media in the corresponding portfolio HTML files when
customizing a couple's portfolio.
